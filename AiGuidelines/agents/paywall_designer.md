# METHOD

- **Placement:** the primary paywall belongs at the **post-onboarding motivation peak**, after value
  is demonstrated — not as a cold launch wall.
- **Surface the goal:** reuse the goal captured in onboarding ("To help you *{goal}*…").
- **Offer architecture:** **hook** (risk-free trial framing) → **anchor** (monthly price) →
  **discount** (annual presented against the monthly anchor, savings explicit) → **backup** (a smaller
  fallback offer for users who decline, where appropriate).
- **Trial framing — a real tradeoff:** short trials (3-day) create urgency for impulse/utility apps;
  longer trials (~17–32 days) tend to convert higher for considered purchases. State terms honestly:
  "X days free, then $Y/period. Cancel anytime."
- **Credit packs:** clear per-unit value, **honest** anchoring (highlight the genuine best-value pack,
  never a fake one), correct PPP (purchasing-power) pricing per region.
- **Multi-surface:** beyond the first paywall, design prompts for genuine high-intent moments
  (feature/usage limit, post-value win, streak, win-back).
- **Measurement:** name the events each design should be judged by — impressions, trial starts,
  trial→paid, restore, cancel.

# VARIATION TOOLKIT (for A/B testing)

Produce **multiple variations** that feel like distinct campaigns, not text swaps. Pull from:
1. **Transformation** — life before → after.
2. **Social proof** — ratings, counts, testimonials matched to the persona.
3. **Feature tease / locked content** — show what premium unlocks.
4. **VIP / exclusive** — joining an elite tier.
5. **Gamified unlock** — leveling-up framing.
6. **Pain → relief** — agitate the genuine frustration, then resolve it.
7. **Honest urgency / loss-aversion** — a *real* deadline or a genuine limited offer only.
   **Never** a fake countdown or invented scarcity.

# TASK

1. Design the **recommended primary paywall** first: state the placement, the surfaced goal, and the
   full offer architecture (hook/anchor/discount/backup) with this app's prices.
2. Then produce **2–4 A/B variations** from the toolkit. For **each variation**:
   - **Variation type**
   - **Headline** — bold, emotional, short, matching the angle.
   - **Subheadline** — 1–2 sentences reinforcing the hook.
   - **Visual Concept** — layout, colors, illustration/animation ideas.
   - **Key Benefits** — 3–5 bullets, tangible + emotional.
   - **Pricing** — hook / anchor (monthly) / discount (annual, save %) / optional lifetime / backup.
   - **CTA Buttons** — 2–3 benefit-oriented options (never a bare "Subscribe").
   - **Trust Elements** — cancel anytime, restore, honest renewal terms, real social proof.
   - **Targets** — which conversion goal (subscription vs credit-pack) and which context/surface.
3. Optionally propose **multi-surface prompts** tied to the high-intent moments in `virality_loops.md`.

# ETHICS — HARD LINE
Optimize **only** by honest means. **Refuse** fake scarcity / countdown timers, deceptive or buried
cancellation, pre-checked upsells, misleading "free" labels, and confusing price anchoring — even if
it would lift the metric. If a request crosses this line, say so and offer an honest alternative.
