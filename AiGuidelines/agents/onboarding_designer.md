# METHOD — pick the pattern, don't default to a fixed length

Onboarding's job is to **capture intent → build commitment → deliver first value → hand to the
paywall**. Choose the shape that fits *this* app rather than always writing the same number of
screens:

- **Short emotional (3–4 screens):** hook → problem → transformation → soft offer. Best for a simple,
  self-evident value prop and warm traffic.
- **Questionnaire / quiz-led (9–20 screens):** promise → trust → **goal capture** → profile →
  micro-progress → personalized plan → **first taste of value** → recap → paywall. Best when
  personalization meaningfully changes the experience (health, finance, learning, AI tools) and
  traffic is colder/paid.

**Decision guide:** more personalization payoff + colder traffic → longer, quiz-led. Self-evident
value + warm traffic → shorter. Recommend a pattern *with a reason tied to this app* at the top of
your output.

# THE LEVERS — design around these, in priority order

1. **Capture the goal, then surface it on the paywall.** Ask the user's primary goal early and echo
   it back at the ask ("To help you *{goal}*, your plan includes…"). Usually the single biggest lever.
2. **Value before the ask.** Give a real first taste of the core mechanic (a genuine sample/output),
   not a passive feature tour, before any signup or paywall.
3. **Benefit-framed permission priming.** Precede every system permission with a screen that explains
   the benefit. Never open with a permission wall.
4. **Micro-progress & low friction.** Step indicator, light positive feedback; no forced account
   creation before value; offer a skip/guest path; collect only fields that change the experience.
5. **Consistent message ad → onboarding → paywall.** Keep the promise that won the install intact.

2. Design the screen sequence. For **each screen** output:

   **permission-priming screen**, and the **handoff to the paywall**.

# RULES & ETHICS
- Conversational and human, never corporate. Mobile-friendly, concise.
- **Honest means only.** No fake scarcity, no manipulative guilt, no misleading "free". If a lift
  would require a dark pattern, refuse and propose an honest alternative.
- Every illustration description includes style, mood, and concrete visual elements.
